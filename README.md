# WALKER

Appli de marche : compteur de pas, durée, distance et énergie estimées, historique des marches.

## Contenu

- `index.html` : version web fonctionnelle (compte les pas avec le capteur de mouvement du téléphone, garde l'historique sur l'appareil). Peut être publiée avec GitHub Pages.
- `design/` : maquette des écrans (accueil, aujourd'hui, planning, résumé de marche, stats, marche en direct, connexion, logo). Fichiers `.dc.html` + `canvas.json`.
- `assets/logo-walker.jpg` : logo de l'appli.

## Publier avec GitHub Pages

1. Dépôt > Settings > Pages.
2. Source : Deploy from a branch, branche `main`, dossier `/ (root)`.
3. Ouvrir l'adresse donnée sur le téléphone, puis « Ajouter à l'écran d'accueil ».
